# Especificación técnica

Cambio exclusivamente documental. `sdd/STATUS.md` recibe una sección de máxima
precedencia; las secciones anteriores se conservan como historia verificable.

La evidencia se ancla a `origin/master` y al run de GitHub Actions ya concluido.
No se modifican contratos, estados de dominio, adapters, perfiles ni migraciones.
