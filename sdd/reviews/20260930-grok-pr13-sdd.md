Tests swap a test provider. Domain, the ticket saga, and `@Scheduled` workers stay out. It is not a Mercado Libre dispatcher and it does not activate the live companion, fiscal emission, or `/sdd.finish`.

The PR title is "Inject DispatcherProvider for loopback HTTP IO." The body matches that scope, points at issue #12, and says StoreCore has no production HTTP client so it does not receive an unused provider. The focused Gradle box is checked. Dual Grok and "no fiscal, no live host, no `sdd.finish`" stay unchecked. The body does not claim CI green, a live companion, or a remote ML dispatcher.
